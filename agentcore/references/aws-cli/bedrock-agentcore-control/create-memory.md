# create-memory

## Description

Creates a new Amazon Bedrock AgentCore Memory resource.

See also: [AWS API Documentation](https://docs.aws.amazon.com/goto/WebAPI/bedrock-agentcore-control-2023-06-05/CreateMemory)

## Options

`--client-token` (string)

> A unique, case-sensitive identifier to ensure that the operation completes no more than one time. If this token matches a previous request, Amazon Bedrock ignores the request but does not return an error.
>
> Constraints:
>
> - min: `0`
> - max: `500`

`--name` (string) \[required\]

> The name of the memory. The name must be unique within your account.
>
> Constraints:
>
> - pattern: `[a-zA-Z][a-zA-Z0-9_]{0,47}`

`--description` (string)

> The description of the memory.
>
> Constraints:
>
> - min: `1`
> - max: `4096`

`--encryption-key-arn` (string)

> The Amazon Resource Name (ARN) of the KMS key used to encrypt the memory data.
>
> Constraints:
>
> - pattern: `arn:[a-z0-9-\.]{1,63}:[a-z0-9-\.]{0,63}:[a-z0-9-\.]{0,63}:[a-z0-9-\.]{0,63}:[^/].{0,1023}`

`--memory-execution-role-arn` (string)

> The Amazon Resource Name (ARN) of the IAM role that provides permissions for the memory to access Amazon Web Services services.
>
> Constraints:
>
> - pattern: `arn:[a-z0-9-\.]{1,63}:[a-z0-9-\.]{0,63}:[a-z0-9-\.]{0,63}:[a-z0-9-\.]{0,63}:[^/].{0,1023}`

`--event-expiry-duration` (integer) \[required\]

> The duration after which memory events expire. Specified as an ISO 8601 duration.
>
> Constraints:
>
> - min: `3`
> - max: `365`
