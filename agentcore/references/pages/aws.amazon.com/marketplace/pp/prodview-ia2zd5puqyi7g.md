## Overview

Coinbase Developer Platform Non-Custodial User Wallets embed programmable, self-custodial crypto wallets in any application, for users and AI agents alike. Developers integrate with a simple API or React SDK; end users can authenticate with a variety of web2-friendly auth methods like email OTP, SMS, Google, Apple, Custom JWT and more, and receive an instant wallet with no seed phrases, no browser extensions, and no separate wallet app. Private keys are secured in Trusted Execution Environments (TEEs), never exposed over the internet, and never accessible to Coinbase.

CDP Non-Custodial User Wallets support three account types: standard EOA accounts (upgradeable via EIP-7702), ERC-4337 Smart Accounts with gas sponsorship and batched transactions, and native Solana accounts. Advanced capabilities include MFA, delegated signing, spend permissions, and compatibility with Wagmi, viem, ethers.js, and the Solana Wallet Standard. Mobile developers can integrate via React Native or Swift SDK.

CDP Non-Custodial User Wallets are natively integrated with Amazon Bedrock AgentCore Payments. AI agents built on AgentCore can be provisioned with CDP wallets to autonomously pay for APIs, data, and digital services via the x402 payment protocol with enterprise controls including spend limits, time-bound delegations, and full transaction observability. For AgentCore developers, wallet usage is metered and billed directly through your AWS account, with no separate Coinbase billing setup required.

### Highlights

- USDC Rewards on wallet balances for eligible developers. Battle-tested infrastructure with high availability and enterprise-grade key security backed by Trusted Execution Environments. Native gas sponsorship on Base and Solana.
- One unified developer platform for non-custodial wallets, onchain swaps, onramp/offramp, SQL-queryable onchain data APIs, x402 agentic payments, and custodial accounts, all accessible under a single API key and billing relationship.
- Natively integrated with Amazon Bedrock AgentCore Payments. Provision CDP wallets for AI agents and users directly from the AgentCore Console with spend limits, delegated signing, and usage billed through your AWS account.
