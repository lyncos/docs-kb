# Microsoft GraphRAG

GraphRAG is a data pipeline and transformation suite that extracts meaningful, structured data from unstructured text using LLMs. It uses a graph-based approach to RAG (Retrieval-Augmented Generation) that uses knowledge graphs to improve reasoning over private datasets.

- [Github](https://github.com/microsoft/graphrag)
- [Docs](https://microsoft.github.io/graphrag/)
