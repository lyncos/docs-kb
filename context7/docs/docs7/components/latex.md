# LaTeX

> Add mathematical notation to a page

Use dollar signs in Markdown or the `<Latex>` component in MDX.

## Usage

```md
Inline: $E = mc^2$

$$
\frac{1}{2}
$$
```

```mdx
<Latex>x^2 + y^2</Latex>
```
