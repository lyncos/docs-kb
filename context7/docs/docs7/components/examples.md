# Request and response examples

> Pin API examples beside the page content

Wrap one or more code fences in `<RequestExample>` or `<ResponseExample>`.

## Usage

````mdx
<RequestExample>
```bash cURL
curl https://api.example.com/users
```
</RequestExample>

<ResponseExample>
```json 200
{"items": []}
```
</ResponseExample>
````
