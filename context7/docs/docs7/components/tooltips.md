# Tooltips

> Explain a word or action on hover

Wrap the text that should trigger the tooltip.

## Usage

```mdx
Read the <Tooltip tip="A short explanation">API reference</Tooltip>.
```

Add `cta` and `href` when the tooltip should include a link.

Read the <Tooltip tip="A short explanation">API reference</Tooltip>.
