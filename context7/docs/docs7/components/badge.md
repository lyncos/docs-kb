# Badges

> Add a small status or version label

Use `<Badge>` for a short label.

## Usage

```mdx
<Badge color="green">Stable</Badge>
<Badge color="purple" shape="pill" stroke>Beta</Badge>
```

Useful props are `color`, `size`, `shape`, `icon`, `stroke`, and `disabled`.
