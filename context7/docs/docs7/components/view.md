# View

> Let readers switch between versions of page content

Sibling `<View>` components form one selector.

## Usage

```mdx
<View title="React" icon="react">
  React instructions.
</View>

<View title="Vue" icon="vuejs">
  Vue instructions.
</View>
```

`title` is required. `icon` and `iconType` are optional.
